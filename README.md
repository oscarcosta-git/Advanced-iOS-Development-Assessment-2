# Drive Social

iOS app for car owners to log trips, track service history, and find mechanics.

## Screens
- **My Trips** — log and view driving trips
- **Leaderboard** — friends ranked by verified km
- **My Car** — vehicle profile and service history
- **Find a Mechanic** — search workshops by rating

## Architecture
Views → ViewModels → Use Cases → Repositories → Domain Models

## Running
Open the `.xcodeproj` in Xcode and press Run.
